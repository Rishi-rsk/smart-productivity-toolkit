# 🎯 Guess the Number Game (Flask Web App)

A web-based version of the classic Guess the Number game built using Python and Flask.

## 🚀 Features
- Random number generation (1–100)
- Dynamic hints (high/low)
- Range narrowing
- Guess history tracking
- Web-based UI

## 🛠️ Tech Stack
- Python
- Flask
- HTML/CSS

## ▶️ Run Locally

```bash
pip install -r requirements.txt
python app.py
